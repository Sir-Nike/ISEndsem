Lab 7 additional 1c: Custodian threshold for final decryption

What the manual asks

Explore threshold collaboration in secure multi-party computation without revealing each party's input.

Start here: the idea in plain English

Encrypt input amounts with Paillier and aggregate them publicly. Split the private exponent into Shamir shares held by different custodians. Refuse final decryption with fewer than the configured number of shares. Once enough custodians cooperate, reconstruct the private exponent locally and decrypt only the aggregate. Lagrange interpolation recovers the secret at x=0.

Step-by-step solution

1. Start the program and select Run. Read the displayed default inputs before changing them.
2. Follow the input prompts. Text is encoded to bytes when required; numeric inputs are checked before cryptographic operations.
3. Read the exercise() function below: it connects the functions in the order needed for this question.
4. Compare the printed output with the expected result, and repeat using a different input.

def exercise():
    """Input: values, custodian count and threshold. Demonstrate threshold-controlled final decryption.
    Output: share distribution, denial below threshold and successful final-total recovery.
    """
    values = [int(x) for x in ask_text("Amounts", "15,25,35").split(",")]
    count = ask_int("Custodians", 3, 2, 10)
    threshold = ask_int("Required custodians", 2, 2, count)
    public, private = paillier_keys(512)
    prime = getPrime(public["n"].bit_length() + 16)
    shares = split_secret(private["lambda"], threshold, count, prime)
    # In a real service, deliver each share privately to a different custodian.
    print("Shares created for custodian numbers:", [x for x, y in shares])
    aggregate = encrypted_sum(public, [paillier_encrypt(public, value) for value in values])
    del private
    try:
        threshold_controlled_decrypt(public, aggregate, shares[: threshold - 1], prime, threshold)
    except ValueError as error:
        print("Below threshold rejected:", error)
    result = threshold_controlled_decrypt(public, aggregate, shares[:threshold], prime, threshold)
    print(
        "Encrypted aggregate:",
        aggregate,
        "Decrypted final total:",
        result,
        "Verified:",
        result == sum(values) % public["n"],
    )


Follow the calls in exercise() from top to bottom. It obtains the inputs, calls the small functions that do the work, and prints intermediate values and the final result. Bytes are shown as hexadecimal when ordinary text would be unreadable. A successful round trip prints a recovered message equal to the input; verification examples also show a changed message being rejected where applicable.

Every function explained

ask_text(label, default)

Input: a prompt and default string. Read text, or use the default when Enter is pressed.
Output: a string. Use ask_text('Message', 'hello') to let the user choose a message.

ask_int(label, default, minimum, maximum)

Input: prompt, default integer, optional inclusive limits. Read and validate a number.
Output: an integer; raise ValueError on bad input. Use for keys, counts, or amounts.

paillier_keys(bits)

Input: desired modulus size. Generate p/q and compute Paillier parameters with g=n+1.
Output: (public dictionary n/g, private dictionary lambda/mu). Keep private values secret.

paillier_encrypt(public, message)

Input: public n/g and integer 0<=message<n. Choose fresh random r coprime to n.
Output: ciphertext g^message * r^n modulo n^2. Same message encrypts differently each time.

paillier_decrypt(public, private, ciphertext)

Input: matching public/private keys and valid ciphertext. Apply L(c^lambda)*mu modulo n.
Output: plaintext integer modulo n. L(u) means (u-1)//n.

encrypted_sum(public, ciphertexts)

Input: public key and iterable of Paillier ciphertexts. Multiply modulo n^2.
Output: encryption of the sum modulo n. No individual plaintext or private key is needed.

split_secret(secret, threshold, count, prime)

Input: secret integer, required share count, total shares and prime field > secret.
Output: list of (x,y) Shamir shares. Any threshold shares reconstruct the secret.

reconstruct_secret(shares, prime, threshold)

Input: distinct Shamir shares, prime and required count. Interpolate polynomial at zero.
Output: secret integer. Reject too few shares or repeated x coordinates.

threshold_controlled_decrypt(public, ciphertext, shares, prime, threshold)

Input: final aggregate ciphertext, public key and enough custodian shares of lambda.
Output: aggregate integer. Reconstruct lambda locally and derive mu; never decrypt inputs here.

exercise()

Input: values, custodian count and threshold. Demonstrate threshold-controlled final decryption.
Output: share distribution, denial below threshold and successful final-total recovery.

main()

Input: terminal choices. Run the exercise safely.
Output: printed results. Use python solution.py and choose a menu option.

What to change during an exam

Change values through the prompts first. For a different scenario, replace the example messages or record fields in exercise(), and keep the cryptographic functions. Match the requested algorithm, key size, mode, and hash exactly. Store IVs/nonces alongside ciphertext when needed. Keep private keys private. Hashing cannot be decrypted; encryption can. A hash by itself does not prove who sent a message.

Notes and limitations

This is Shamir threshold CONTROL over Paillier decryption, not a cryptographically distributed threshold-Paillier protocol: the private exponent is reconstructed in one process. That distinction is explicit. Production threshold decryption instead combines partial decryptions without recreating the full private key. Shares, roles and custodian delivery are simulated here; shares are not printed.
